DFDC face head v1: face swaps (type b), frozen DINOv3 + linear head on face crops (31 Oct 2026)

Data (src/features/extract_dfdc_faces.py; frames, crops and features stay on the laptop, never published):
  DFDC training parts 0-2: 424 real videos, up to 2 fakes each, 6 frames per video, SAM 3 faces on the
  real frame, the SAME box on the fake frame (true pairs: only the face differs), 4 random copies each.
  A fake crop counts only if the face really changed (inner SAM box difference > 2x the frame's).
  -> 2,814 real faces, 3,525 fake faces (1,312 unchanged fake crops dropped; e.g. the other, unswapped person).
  DFDC part 3 (held out, dev): 968 real / 964 fake faces (app crop, k = 4.0), 495 videos.
  WildDeepfake test: its own ready-made (tighter) crops, 806 sequences.

Findings:
  1. Head F (the app's face check until now) cannot see face swaps at all (AUC 0.44, below chance).
  2. The DFDC head learns real swap traces (WildDeepfake, never seen, AUC 0.73), but frozen features
     are weak for swaps: at a strict line it catches only ~15-20% of swaps. This matches GenD
     (frozen DINOv3 linear probe 74.9 mean AUROC; LayerNorm-tuning 91.3).
  3. The curve still rises (part 3 AUC 0.55 -> 0.68 -> 0.72): more DFDC parts would help a little;
     the big step would be LayerNorm-tuning, which does not fit the time left.
  -> Face swaps (b) are "limited" in this version, stated openly with these numbers.
  Caveat: DFDC part 3 is a dev set (used to pick the weight decay); WildDeepfake is the untouched test.
