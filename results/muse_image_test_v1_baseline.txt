== Metadata ==
Every file carries XMP with iptcExt:DigitalSourceType =
http://cv.iptc.org/newscodes/digitalsourcetype/trainedAlgorithmicMedia (no C2PA block).
The detector reads pixels only, so it never sees this. A metadata check catches unchanged files with
certainty; WhatsApp, screenshots and many editors strip it, so the pixel detector is still needed.
